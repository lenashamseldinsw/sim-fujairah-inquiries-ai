# 🚀 Quick Deploy to Streamlit Cloud

## 📦 Repository Ready!
**GitHub:** https://github.com/lenashamseldinsw/sim-fujairah-inquiries-ai

---

## 3-Step Deployment

### Step 1: Go to Streamlit Cloud
👉 https://share.streamlit.io

### Step 2: Create App
- Click **"New app"**
- Repository: `lenashamseldinsw/sim-fujairah-inquiries-ai`
- Branch: `main`
- Main file: `app.py`

### Step 3: Add Secrets
Click **"Advanced settings"** and paste:

```toml
[users]
admin_username = "admin"
admin_password = "admin123"
demo_username = "demo"
demo_password = "demo123"
```

### Deploy!
Click **"Deploy!"** and wait 2-3 minutes.

---

## ⚠️ Before Production
Change passwords in Streamlit Cloud secrets!
